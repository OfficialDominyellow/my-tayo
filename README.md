# 🚌 꼬마버스 타요 동네 순찰대 (Tayo Little Bus Patrol)

5살 아들과 아빠가 함께 집에서 재미있게 즐길 수 있는 **어린이용 3D 교통안전 자동차 게임**입니다.  
실제 애니메이션 일러스트(`my_resources/tayo_rani_gani_rogi.jpg`)를 기반으로 캐릭터 외형을 정밀 재현하였으며, **Three.js + @dimforge/rapier3d 기반의 현실적인 차량 물리 엔진**이 탑재되어 있습니다.

---

## 🌟 주요 업그레이드 및 기능

### 1. 꼬마버스 4총사 비주얼 정밀 재현 (`src/bus-model.ts`)
- **타요 (120)**: 이마 상단 블랙 뱃지 `120`과 3개의 둥근 표시등, 뺨을 감싸는 노란색 곡선 장식, 톡 튀어나온 3D 캡슐 코, 3D 루프 AC 유닛, 사이드미러, 랩어라운드 헤드라이트.
- **로기 (1000)**: 초록 바디에 상단 `1000` 노선 뱃지와 3개 표시등, 연두/노랑 볼 곡선, 쾌활한 미소.
- **라니 (02)**: 상냥한 노란 바디에 `02` 뱃지와 3개 표시등, 핑크 볼터치, 아담하고 귀여운 차체 비율.
- **가니 (1339)**: 가니 특유의 상단 화이트 바이저 바에 `1339` 뱃지와 3개 표시등, 차분하고 따뜻한 미소.

### 2. Rapier3D 기반 정통 차량 물리 엔진 (`src/physics.ts`)
- **Rapier VehicleController 탑재**:
  - 4륜 레이캐스트 서스펜션, 마찰력, 브레이크, 엔진 구동력 물리 시뮬레이션.
- **고정 시간 간격 분리 (Decoupled fixedUpdate)**:
  - 렌더링 프레임레이트와 관계없이 `1/60초(16.67ms)` 고정 주기로 물리를 연산하여 지터와 관통을 방지.
- **무게중심 하향 (Lowered CoM)**:
  - 차체 무게중심을 바닥 쪽(-0.55m)으로 내려 5세 아이의 급회전 조작에도 차가 쉽게 전복되지 않음.
- **속도 감응형 조향**:
  - 저속(0~10km/h)에서는 0.52rad(~30도)로 민첩하게 회전하고, 고속에서는 0.22rad로 제한하여 스핀 방지.
- **저속 회전 보조**:
  - 정지 상태에서 아이가 핸들을 꺾을 때 부드러운 토크 보조를 주어 조작 스트레스 해소.
- **차체 바로세우기 (Unflip / Recovery - 단축키: `R`)**:
  - 차체가 끼이거나 뒤집혔을 때 버튼이나 `R`키를 누르면 방위각을 유지한 채 공중에서 안전하게 바로 서서 착지.
- **테스트용 완만한 경사로(Ramp)**:
  - 마을 남동쪽에 완만한 경사로와 전망 데크가 설치되어 언덕 등판 및 서스펜션 테스트 가능.

### 3. 라즈베리파이 5 (Raspberry Pi 5) 최적화
- **WebGL 2 지원**: 최신 고성능 WebGL 컨텍스트 사용.
- **디버그 HUD 탑재**: 화면 좌상단에 실시간 **FPS, Frame Time(ms), Physics Time(ms), 속도(km/h)** 표시.
- **저사양 모드 토글 (단축키: `L` 또는 상단 ⚡ 버튼)**:
  - 그림자 맵 비활성화 및 픽셀 비율 1.0 고정으로 Raspberry Pi 5 및 저사양 기기에서 60 FPS 보장.

## 🎮 조작 방법

| 기능 | 키보드 키 | 온스크린 터치 버튼 | 게임패드 (USB) |
| :--- | :--- | :--- | :--- |
| **전진 (가속)** | `↑` 또는 `W` | 오른쪽 초록 `⬆` | `A` 버튼 / 트리거 R |
| **후진** | `↓` 또는 `S` | 오른쪽 주황 `⬇` | `B` 버튼 / 트리거 L |
| **좌/우 회전** | `←`, `→` 또는 `A`, `D` | 왼쪽 하늘색 `◀`, `▶` | 아날로그 스틱 / 십자키 |
| **브레이크** | `B` | 오른쪽 빨강 `🛑` | `X` 버튼 |
| **경적 (빵빵!)** | `스페이스바 (Space)` | 중앙 노랑 `🎺` | `Y` 버튼 / `RB` |
| **바로세우기 (복구)** | `R` | 상단 `🔄 바로세우기` | `Select / Back` 버튼 |
| **시점 변경** | `C` | 중앙 보라 `📷` | - |
| **저사양 모드** | `L` | 상단 `⚡ 저사양` | - |

## 💻 실행 및 빌드 방법

### 개발 모드 실행 (Vite)
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

### 프로덕션 빌드 (배포용 경량 번들)
```bash
npm run build
```
`dist/` 폴더에 최적화된 파일들이 생성됩니다.

### 라즈베리파이 5에서 전용 게임기(Kiosk)로 실행
1. 빌드된 `dist/` 폴더 또는 소스를 라즈베리파이로 복사합니다.
2. 터미널에서 전체화면 아케이드 모드로 실행:
   ```bash
   chromium-browser --kiosk --noerrdialogs --disable-infobars http://localhost:3000
   ```
   *(종료는 `Alt + F4`)*
