# 🚌 꼬마버스 타요 & 긴급출동 구조대: 동네 순찰대 & 4세 놀이교실 (Commercial Edition)

4~5세 아이와 부모님이 함께 즐기는 **3D 오픈월드 드라이빙 & 긴급구조 & 유아 교육 게임**입니다.  
**Three.js + @dimforge/rapier3d** 기반의 정통 차량 물리 엔진, 실제 도로망 규격을 반영한 520m×520m 대도시·순환고속도로 맵, **경찰차(패트)·소방차(프랭크)·구급차(앨리스)** 변신 및 긴급출동 콘텐츠, **F1 레이싱카(페라리·메르세데스)**, **우리가족(선율·태율·엄마·아빠) SD 캐릭터**, 그리고 **한글·숫자·영어·안전상식 4세 놀이교실**이 탑재되어 있습니다.

---

## 🌟 주요 기능 및 업데이트 하이라이트

### 1. 7종의 플레이어블 차량: 꼬마버스 4총사 + 긴급구조대 3총사 (`src/bus-model.ts`)
- **꼬마버스 4총사**:
  - **타요 (120)**, **로기 (1000)**, **라니 (02)**, **가니 (1339)** — 3D 눈 깜빡임·표정 변화, 루프 에어컨, 사이드미러, 휠하우스 아치 및 일체형 서스펜션 스트럿 탑재.
- **긴급구조대 3총사 (직접 운전 가능 & AI 순찰)**:
  - **🚔 패트 (112 경찰차)**: 네이비/화이트 순찰 도색, 루프 적·청 경광등 스트로브, 경찰서 방범 순찰 미션.
  - **🚒 프랭크 (119 소방차)**: 레드 소방 도색, 루프 연장 사다리 및 **3D 물대포 노즐(`💦`)**, 소방서 화재 진압 미션.
  - **🚑 앨리스 (119 구급차)**: 화이트/에메랄드 응급 도색, 적십자 마크, 병원 응급 이송 및 건강 회복 미션.

### 2. 경찰서 · 소방서 · 병원 3D 랜드마크 & 긴급출동 미션 (`🚨 긴급출동!`)
- **🚓 112 용감한 경찰서 (`-84, 28`)**: 경찰 방패 엠블럼, 옥상 레이더 안테나, 순찰 출동 패드.
- **🚒 119 용감한 소방서 (`-84, 86`)**: 2베이 소방 차고와 **3D 화염이 타오르는 화재 훈련 타워**. 가까이 가서 **`🚨`(단축키 `F`)** 버튼을 누르면 시원한 **3D 물대포 물줄기**가 발사되어 불을 진압하고 별 3개 보상을 획득합니다!
- **🏥 튼튼 어린이 종합병원 (`84, -28`)**: 대형 입체 적십자 마크, 옥상 헬리패드(`H`), 떠오르는 치유 십자가 파티클.
- 상단 **`🚨 긴급출동!`(단축키 `Q`)** 버튼을 누르면 소방서 화재 진압 / 경찰서 순찰 / 병원 구급 이송 미션이 즉시 시작됩니다.

### 3. 🏎️ 페라리 F1 & 메르세데스 F1 그랑프리 머신 + 중립 시티카
- 외곽 순환 고속도로의 부드러운 곡선 코너를 따라 **스쿠데리아 페라리 F1 (`#16`)** 과 **메르세데스-AMG 페트로나스 F1 (`#44`)** 오픈휠 레이싱카가 고속 주행하며, 옆을 스쳐 지나갈 때 실감나는 **F1 고회전 배기음(Doppler Pass-by)** 이 울립니다.
- 시내 도로에는 노란 시티세단, 민트 패밀리 SUV 등 중립 차량이 함께 주행합니다.

### 4. 520m × 520m 실제 규격 도로망 & 100% 실시간 동기화 미니맵 (`src/world.ts`, `src/game.ts`)
- **단순 타일 겹침 ZERO**: 모든 직선 도로는 교차로 정지선에서 정확히 끊어지며, **중앙 원형 로터리(분수대 광장)**, **4거리 교차로(횡단보도·정지선)**, **3거리 T자 교차로**, **외곽 곡선 코너(`R=38m` 아크 지오메트리)** 가 매끄럽게 연결됩니다.
- **실시간 미니맵 레이더**: `world.minimapRoads` 데이터를 기반으로 중앙 로터리, 직선 도로, 외곽 곡선 코너, 랜드마크, 승객/목적지, F1 머신(`🏎️`), 긴급차량(`🚓🚒🚑`), 긴급출동 타겟 링을 100% 일치하게 렌더링합니다.
- **도로 이탈 안전 가드**: 도로 밖 잔디로 벗어나면 부드럽게 감속하며 도로 복귀 안내를 제공합니다.

### 5. 🚸 신호등 연동 3D 보행자 &  streetlights 야간 가로등 점등
- **신호등 연동 보행자**: 차량 신호가 빨간불일 때 안전모자를 쓴 귀여운 3D 보행자들이 팔다리를 흔들며 횡단보도를 건너갑니다. 정지선 앞에서 멈춰 양보하면 **보행자 보호 칭찬 보너스**를 받습니다!
- **야간 가로등 점등**: 시간대를 **노을/밤(`T` 키)** 으로 바꾸면 도로변 아치형 가로등 전구와 바닥 원형 불빛 풀(Light Pool)이 일제히 켜집니다.

### 6. 👨‍👩‍👦‍👦 우리가족 SD 캐릭터 (선율이 · 태율이 · 엄마 · 아빠)
- `my_resources`의 가족 얼굴 사진을 정밀 크롭하여 8개 정류장 중 **전체 맵에 딱 1명씩만 고유하게(중복 없이)** 등장하며, 나머지 정류장에는 귀여운 동물 친구들이 대기합니다.

### 7. 🎓 4세 맞춤 놀이교실 (한글 · 숫자 · 영어 · 🚦 안전·상식)
- 승객을 태우거나 상단 **`🎓 놀이교실`(`E` 키)** 버튼을 누르면 **한글놀이**, **숫자놀이**, **영어놀이**, 그리고 새롭게 추가된 **🚦 안전·생활상식(119 소방차, 112 경찰차, 병원 구급차, 횡단보도 건너기)** 퀴즈·따라쓰기·선잇기를 즐길 수 있습니다.

## 🎮 조작 방법

| 기능 | 키보드 키 | 온스크린 터치 버튼 | 게임패드 (USB) |
| :--- | :--- | :--- | :--- |
| **전진 (가속)** | `↑` 또는 `W` | 오른쪽 초록 `⬆` | `A` 버튼 / 트리거 R |
| **후진** | `↓` 또는 `S` | 오른쪽 주황 `⬇` | `B` 버튼 / 트리거 L |
| **좌/우 파워핸들** | `←`, `→` 또는 `A`, `D` | 왼쪽 하늘색 `◀`, `▶` | 아날로그 스틱 / 십자키 |
| **브레이크** | `B` | 오른쪽 빨강 `🛑` | `X` 버튼 |
| **경적 (빵빵!)** | `스페이스바 (Space)` | 중앙 노랑 `🎺` | `Y` 버튼 / `RB` |
| **사이렌 & 소방 물대포** | `F` | 중앙 적·청 `🚨` | - |
| **긴급출동 미션 시작** | `Q` | 상단 `🚨 긴급출동!` | - |
| **4세 놀이교실 열기** | `E` | 상단 `🎓 놀이교실` | - |
| **카메라 시점 (5종)** | `C` | 중앙 보라 `📷` | - |
| **낮 / 노을 / 밤 전환** | `T` | 상단 `☀️ 낮` | - |
| **바로세우기 (복구)** | `R` | 상단 `🔄 바로세우기` | `Select / Back` 버튼 |
| **저사양 모드** | `L` | 상단 `⚡ 저사양` | - |

